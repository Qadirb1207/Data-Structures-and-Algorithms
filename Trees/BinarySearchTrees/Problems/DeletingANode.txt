Algorithm: Delete a Node from a Binary Search Tree (BST)
Goal: Delete a given value from a BST while keeping the BST rules correct.

Steps
Start from the root node.

1. If the current node is null, the value does not exist in the tree. Return null.

2. If the value is smaller than the current node's value, search the left subtree and update node.left with the returned node.

3. If the value is greater than the current node's value, search the right subtree and update node.right with the returned node.

4. If the value matches the current node, delete it using one of these three cases:

        Case 1: No child — Return null.

        Case 2: One child — Return the existing child, so it takes the deleted node's place.

        Case 3: Two children — Find the smallest value in the right subtree (the inorder successor), copy its value into the current node, and then delete the successor from the right subtree.

5. Return the current node so the parent can reconnect the updated subtree.

6. In the main delete() method, assign the returned node to root to handle the case where the root itself changes.

Remember
Search → Find the node → Handle its children → Return the node → Reconnect the subtree.

The most important idea is that every recursive call returns the node that should represent that subtree after deletion.
