# This is for Your Information Qadir!!!

اسينLinkedList کيArray جي جڳھ تي استعمال ڪري سگھون ٿا. مثال طور ڪٿي اسين جيڪڏھن Array کي استعمال ڪيو آھي، ان جي جڳھ تي اسين LinkedList کي استعمال ۾ آڻي سگھون ٿا. 
مثال:- جيڪڏھن مون ڪوئي System ٺاھڻو آھي ته آءٌ ان ۾ معلومات کي رکڻ لاءِ Array جي جاء تي LinkedList  کي استعمال ڪري سگھان ٿو. جيئن مون کي ملازمن (Employees) جي معلومات جمع ڪرڻي آھي ته آءٌ ملازم (Employee) جماعت (Class) ٺاھي انھي کي LinkedList ۾ استعمال ڪري سگھان ٿو. 
مثال طور جيئن عام طور تي اسان LinkedList جي حصي (Node) ۾ عدد (Integers) يا لفظ (Strings) استعمال ڪندا آهيون ان جي جڳھ تي اسين ملازم (Employee) جماعت (Class) جون شيون (Objects) استعمال ڪري سگھون ٿا.
